# Binary Block Inclusion

A Python project exploring binary patterns, block inclusion logic, and blockchain-style timestamps.

## Features

- Binary to decimal conversion
- Pattern analysis
- Block inclusion detection
- **Blockchain with binary timestamps** - Generate blocks with Unix timestamps converted to binary
- SHA-256 hashing with binary representation

## Running the Project

```bash
python binary_blocks.py
```

## Project Structure

- `binary_blocks.py` - Main module with binary operations, block inclusion logic, and blockchain implementation
- `README.md` - Project documentation
- `.github/copilot-instructions.md` - Workspace setup instructions

## How It Works

1. **Binary Patterns**: Converts binary strings to decimal values
2. **Block Inclusion**: Detects specific bit patterns ("01", "11", "10") within binary strings
3. **Blockchain Timestamps**: 
   - Captures current Unix timestamp
   - Converts to binary representation
   - Creates blockchain blocks with SHA-256 hashing
   - Displays binary hashes for cryptographic verification
