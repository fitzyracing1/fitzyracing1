# fitzyracing1

A combined snapshot of projects and working folders.

Each top-level directory is a separate project. Dependencies (`node_modules`,
Python virtual environments), build output, model weights, large binaries, and
all credential files have been excluded — see `.gitignore`. To run any project,
install its dependencies from its own manifest (`package.json`,
`requirements.txt`, etc.).
