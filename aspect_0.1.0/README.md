# Aspect 0.1.0

WiFi Signal Blocker - Block WiFi signals and information requests.

## Description

This program blocks WiFi signals and prevents information requests by disabling the WiFi adapter on Windows systems.

## Features

- Disables WiFi adapter to block signals
- Prevents WiFi information requests
- Administrator privileges recommended for full functionality

## Usage

Run the main program (may require Administrator privileges):

```bash
python main.py
```

To run as Administrator, open PowerShell as Administrator and run:
```bash
python main.py
```

## Requirements

- Python 3.6+
- Windows OS
- Administrator privileges (recommended)
