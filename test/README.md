# Computer Life

A small artificial-life simulation built with plain HTML, CSS, and JavaScript.

## Run

1. Open `index.html` in your browser.
2. Press **Start** to simulate.
3. Click or drag on the world to add organisms.

## Controls

- **Start/Pause**: Run or pause the ecosystem.
- **Step**: Advance one tick.
- **Seed**: Create a fresh world.
- **Clear**: Empty the world.
- **Speed**: Change ticks per second.
- **Food growth**: Control how much food appears over time.
- **Mutation**: Increase trait changes when organisms reproduce.
