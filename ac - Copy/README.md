# Binary Block Inclusion

A Python project exploring binary patterns and block inclusion logic.

## Features

- Binary to decimal conversion
- Pattern analysis
- Block inclusion detection

## Running the Project

```bash
python binary_blocks.py
```

## Project Structure

- `binary_blocks.py` - Main module with binary operations and block inclusion logic
- `README.md` - Project documentation
- `.github/copilot-instructions.md` - Workspace setup instructions
