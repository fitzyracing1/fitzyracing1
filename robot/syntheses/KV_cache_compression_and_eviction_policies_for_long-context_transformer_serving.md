The brief synthesizes all eight turns into a self-contained reference document. A few notes on the structural choices:

The thesis foregrounds the irreversibility and compounding nature of eviction decisions rather than just the memory cost — that's the thread that ran through every turn, from NIAH retrieval failure to multi-turn re-pinning to speculative decoding rotation matrix conflicts.

The five insights are ordered by increasing system complexity: single-policy failure → head heterogeneity → hardware arithmetic → multi-turn dynamics → cross-model constraints. Each builds on the previous.

The open question deliberately goes beyond anything we discussed directly — the batch scheduling angle is the natural next frontier once you accept that recomputation is sometimes right but treat it as a local per-sequence decision rather than a global resource allocation problem.
